# Atelon branding checklist (Phase 1)

Do these first; domains and handles can disappear overnight.

- [ ] Search "Atelon" in quotes on Google, the App Store and Google Play
- [ ] Domain: atelon.com, atelon.in or atelon.ai (best available)
- [ ] Handles: Instagram, X, YouTube
- [ ] Trademark search: IP India public search and WIPO Global Brand Database for "Atelon" plus sound-alikes (Athlon, Ateel), especially vehicle, software and information-service classes
- [ ] Quick check by a trademark attorney before investing in branding
- [ ] Tagline (pick one): "Atelon, every machine in 3D" / "Atelon, the AI vehicle atlas"
- [ ] Use Atelon everywhere: repo, app ID `com.atelon.app`, Vercel and Render project names, style guide

Approved brand masters live in `assets/logo/`: light/dark 4K PNGs, transparent light/dark 4K PNGs, and light/dark SVGs. Run `npm run icons` to generate themed web lockups, favicon, PWA icons, Apple touch icon and the mobile source icon.
Update `apps/web/src/lib/site.ts` once the domain is decided.
